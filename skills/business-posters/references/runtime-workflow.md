# 使用说明

## 能力边界

- 只生成“经营日历”和“经营月报”。
- “收款日历”、“到账日历”属于经营日历。
- “本月经营情况”、“上月生意怎么样”属于经营月报。
- 经营日报、基础数据查询、客户欠款下钻和对账单不属于本技能。

## 默认值

- 未指定月份时，使用 `Asia/Shanghai` 当前月。
- “上个月”使用上一个完整自然月。
- 未指定保存位置时，使用当前工作目录的 `经营海报输出/`。
- 只说“智慧记图报”或“图报”且无法判断类型时，询问要经营日历还是经营月报。

## 执行

经营日历只执行一次：

```bash
node <skill-root>/scripts/generate-calendar.mjs --month YYYY-MM --output <absolute-png-path>
```

经营月报只执行一次：

```bash
node <skill-root>/scripts/generate-monthly-report.mjs --month YYYY-MM --output-dir <absolute-directory>
```

- 生成脚本会自行检查运行环境、内嵌图片、渲染能力、`ailit >= 0.8.1`、必要命令和智慧记连接。
- 不在调用前额外执行诊断、安装、登录或升级命令。
- 不把用户文本拼接进 Shell 命令。月份只传入 `YYYY-MM`，输出位置使用完整参数。
- 目标文件已存在时停止，不覆盖。
- 未经用户要求，不上传图片，不生成可编辑文件或数据文件。

## 结果与失败

- 成功时展示返回的 PNG，只补充一句结果。
- 失败时只转述返回的 `user_message`，然后停止。
- 不向用户展示命令、路径、JSON、依赖、网络输出、重试、安装过程、错误码或内部字段。
- 失败后不阅读源码、不自行修改技能、不手动安装依赖、不重复执行。

## 数据与版式

- 只读取经营数据，不在智慧记中新建、修改或删除业务数据。
- 任一数据分页、金额、字段或状态校验失败时停止，不将失败当作 0。
- 保留现有图片结构、手机版式和指标口径。
- 修改数据适配或口径前，分别读取 [经营日历数据说明](calendar-data-contract.md) 和 [经营月报数据说明](monthly-report-data-contract.md)。
